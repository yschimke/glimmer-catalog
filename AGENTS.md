# Repository instructions

Read `README.md` first. This repository owns the Glimmer catalog, its vendored sample catalog, and
the local Compose Multiplatform port.

## Catalog inventory

- The authored `:catalog` inventory lives in `@CatalogGroup`, `@CatalogComponent`, and
  `@CatalogVariant` annotations. `catalog.spec.json` is cover-sheet metadata, not a second inventory.
- `:samples-catalog` is vendored upstream source, so its `groups` inventory is generated by
  `scripts/samples-spec.mjs`. Never annotate or directly edit files below its `upstream/` package;
  import fixes are patches under `samples-catalog/patches`.
- Every published component needs a real Glimmer kit reference. Figma is read-only and the kit is
  authoritative (`.design-parity.json` is `design-led`).

## UI Builder

- `ui-builder.policy.json` owns catalog-level policy. Per-component decisions belong in
  `@BuilderComponent` beside the preview that demonstrates the real Glimmer callsite.
- Run `node scripts/check-ui-builder.mjs` after discovery. A schema-valid palette of wrappers or
  placeholders is not sufficient; the contract requires all discovered Glimmer APIs.
- Android native rendering is authoritative. Browser rendering remains explicitly approximate
  until the builder links the local CMP port.

## Vendored CMP fork

- `vendor/glimmer-upstream.json` pins the released sources jar and the immutable CMP revision.
- Keep upstream packages and Apache headers. Mark portability changes with `CMP-PORT`, document
  them in `vendor/README.md`, and add every edited file to `scripts/verify-glimmer-vendor.mjs`.
- A changed published byte requires a new `portRevision`; never overwrite an existing Maven version.

## Git and generated outputs

- `main` is protected; use `agent/...` branches and conventional commit subjects.
- Never attribute a commit to an AI agent.
- Generated branches live in `yschimke/glimmer-catalog-out`. Do not delete predecessor branches
  from another output repository until the replacement workflow has published and been verified.

## Verification

Use `scripts/agent-gradle.sh`, not bare Gradle, for automated builds. The core checks are:

```sh
scripts/agent-gradle.sh --exclusive \
  :catalog:assemble :catalog:composePreviewDiscover :catalog:test \
  :samples-catalog:assemble :samples-catalog:composePreviewDiscover \
  :vendor:glimmer:compileKotlinJvm :vendor:glimmer:compileKotlinWasmJs \
  :glimmer-desktop:test publishGlimmerCmpToBuildDir ktfmtCheck
node scripts/check-ui-builder.mjs
node scripts/samples-spec.mjs --check
node scripts/kit-gaps.mjs --check
node --test scripts/*.test.mjs
scripts/design-map.sh --check
node scripts/verify-glimmer-vendor.mjs
```
